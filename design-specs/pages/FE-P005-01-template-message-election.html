화면 요소 설명

1. 탭 메뉴

문자 템플릿 탭 일반문자 / 광고문자 / 선거문자
현재 활성 탭 선거문자 (강조 표시)

2. 공직선거법 규정 안내

표시 내용 - [선거] 표기 필수
- 발송 시간 07:00~23:00
- 투표일 발송 불가
- 금지어 제한
- 080 수신거부 필수
스타일 경고성 알림 (warning alert)

3. 검색 및 필터

카테고리 필터 전체/지방선거/국회의원선거/대통령선거
검색 대상 템플릿명, 후보자/정당명

5. 템플릿 목록 테이블

표시 컬럼 - NO (순번)
- 템플릿명
- 후보자/정당명
- 타입 (SMS/LMS/MMS)
- 080 번호
- 등록일
- 관리

8. [선거] 문구 입력

형식 [선거] + 후보자명 또는 정당명
필수 여부 필수
입력 예시 - [선거] 홍길동
- [선거] 한국당
최대 길이 20자 (40byte)

9. 선거운동정보

필수 여부 선택
최대 길이 20자 (40byte)
입력 예시 기호1번 홍길동 선거사무소

11. 메시지 내용

바이트 제한 SMS 90byte / LMS,MMS 2000byte
변수 버튼 #{이름}, #{전화번호} (제한적 변수)
금지어 검사 저장 전 금지어 검사 필수

12. 금지어 검사 버튼

기능 메시지 내 금지어 포함 여부 검사
검사 대상 비방, 허위사실, 흑색선전 관련 단어
API 호출 POST /api/v1/templates/election/check-forbidden

13. 금지어 검사 결과

통과 ✅ 초록색, "금지어가 발견되지 않았습니다"
실패 ❌ 빨간색, 발견된 금지어 목록 표시
등록 조건 금지어 검사 통과 필수

API 명세

POST
/api/v1/templates/message/election
// Request
{
  "templateName": "기호1번 홍길동",
  "category": "local_election",
  "messageType": "LMS",
  "electionLabel": "홍길동",   // [선거] 뒤 문구
  "electionInfo": "기호1번 홍길동 선거사무소",
  "rejectNumber": "080-111-2222",
  "content": "#{이름}님, 안녕하세요...",
  "variables": ["이름", "전화번호"],
  "images": []
}
POST
/api/v1/templates/election/check-forbidden
// Request
{
  "content": "메시지 내용..."
}

// Response
{
  "passed": true,
  "forbiddenWords": []
}
// 또는
{
  "passed": false,
  "forbiddenWords": ["비방", "허위"]
}

데이터 모델

interface ElectionMessageTemplate {
  id: string;
  templateName: string;
  category: ElectionCategory;
  messageType: 'SMS' | 'LMS' | 'MMS';
  electionLabel: string;      // [선거] 옆 문구
  electionInfo?: string;      // 선거운동정보
  rejectNumber: string;       // 080 수신거부
  content: string;
  variables: string[];        // 제한: 이름, 전화번호만
  images?: string[];
  forbiddenCheckPassed: boolean;
  createdAt: Date;
  updatedAt: Date;
}

type ElectionCategory = 
  | 'local_election'     // 지방선거
  | 'congress_election'  // 국회의원선거
  | 'president_election';// 대통령선거
