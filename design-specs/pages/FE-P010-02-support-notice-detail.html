화면 요소 설명

1. 브레드크럼 네비게이션

요소 Breadcrumb
기능 현재 페이지 위치를 계층 구조로 표시
인터랙션 - 상위 메뉴 클릭 시 해당 페이지로 이동
- "공지사항" 클릭 시 목록 페이지로 이동

2. 공지사항 헤더

구성요소 - 공지 배지 (상단 고정 공지 표시)
- 공지사항 제목
- 등록일 / 조회수
배지 조건 isPinned: true인 경우 "공지" 배지 표시
조회수 처리 상세 페이지 진입 시 자동 조회수 +1 증가

3. 공지사항 본문

요소 HTML 컨텐츠 영역
표시 내용 - 서식이 적용된 HTML 컨텐츠 렌더링
- 이미지, 테이블 등 포함 가능
- 링크 클릭 시 새 탭에서 열림
스타일링 - 본문 폰트: 14px, line-height 1.8
- 최소 높이: 300px
- 패딩: 24px

4. 첨부파일 영역

표시 조건 첨부파일이 있는 경우에만 표시
표시 정보 파일명, 파일 크기 (KB/MB)
인터랙션 클릭 시 파일 다운로드
지원 형식 PDF, DOC, DOCX, XLS, XLSX, JPG, PNG

5. 이전/다음글 네비게이션

기능 이전글, 다음글로 빠르게 이동
표시 정보 이전/다음 공지사항 제목
처리 규칙 - 이전글 없음: "이전 글이 없습니다" 표시
- 다음글 없음: "다음 글이 없습니다" 표시
- 제목 30자 초과 시 말줄임 처리

6. 목록으로 버튼

버튼 목록으로
기능 공지사항 목록 페이지로 이동
동작 - 이전 목록 페이지의 필터/페이지 상태 유지
- URL: /support-notice.html

데이터 모델

interface NoticeDetail {
  id: string;
  title: string;
  content: string;        // HTML 형식
  isPinned: boolean;
  viewCount: number;
  attachments: Attachment[];
  prevNotice?: NoticeLink;
  nextNotice?: NoticeLink;
  createdAt: Date;
}

interface Attachment {
  fileName: string;
  fileSize: number;
  downloadUrl: string;
}

interface NoticeLink {
  id: string;
  title: string;
}
