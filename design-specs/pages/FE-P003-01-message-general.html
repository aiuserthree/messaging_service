1
GNB 네비게이션
▼
상단 글로벌 네비게이션 바입니다. 사용자가 주요 메뉴로 빠르게 이동할 수 있도록 합니다.
메뉴 연결 페이지
문자 발송 message-send-general.html

템플릿 template-message.html
주소록 addressbook.html
발송관리 send-result.html
2
발신번호 선택
▼
등록된 발신번호 목록에서 선택합니다. 승인 완료된 번호만 표시됩니다.
항목 필수 설명
발신번호 필수 승인완료 번호만 선택 가능
💡 비즈니스 규칙
• 발신번호가 없는 경우 "새 발신번호 등록하기" 클릭 시 mypage-caller-number.html로 이동
• 발신번호별 잔여 포인트가 표시됨
GET /api/v1/caller-numbers Response: { callerNumbers: [{ id, number, status, balance }] }
3
수신번호 입력
▼
메시지를 받을 수신자의 전화번호를 입력합니다. 3가지 방식을 지원합니다.
입력 방식 설명
직접입력 한 줄에 하나씩 번호 입력
주소록 저장된 주소록에서 선택
엑셀 업로드 XLSX 파일 업로드 (최대 10,000건)
⚠️ 검증 규칙
• 숫자만 입력 가능 (하이픈 자동 제거)
• 중복 번호 자동 제거
• 수신거부 번호 자동 제외
4
메시지 내용
▼
발송할 메시지의 타입을 선택하고 내용을 작성합니다.
타입 용량 단가
SMS 90 byte 7.4원
LMS 2,000 byte 24.5원
MMS 2,000 byte + 이미지 59.2원
💡 변수 치환
#{이름}, #{전화번호} 변수를 사용하면 수신자별로 개인화된 메시지 발송 가능
// 바이트 계산 한글: 2byte, 영문/숫자: 1byte SMS 90byte 초과 시 LMS 전환 안내 모달 표시
5
발송 시간
▼
즉시 발송 또는 예약 발송을 선택합니다.
옵션 설명
즉시 발송 발송하기 클릭 즉시 발송
예약 발송 지정 일시에 발송 (현재 이후만 선택 가능)
⚠️ 주의사항
예약 발송 선택 시 날짜/시간 선택 필드가 노출됩니다.
6
발송 버튼
▼
테스트 발송과 실제 발송을 수행하는 버튼입니다.
버튼 동작
테스트 발송 본인 번호로 1건 테스트 발송
발송하기 전체 수신자에게 발송
POST /api/v1/messages/send Request: { sendType: 'GENERAL', callerNumber: string, recipientNumbers: string[], messageType: 'SMS' | 'LMS' | 'MMS', content: string, sendMode: 'IMMEDIATE' | 'SCHEDULED', scheduledAt?: string }
⚠️ 발송 전 검증
• 필수 항목 미입력 체크
• 잔액 부족 체크 → 충전 안내
• 발송 확인 모달 표시
7
메시지 미리보기
▼
실제 수신자가 받게 될 메시지를 휴대폰 화면 형태로 미리 보여줍니다.
💡 실시간 반영
• 메시지 내용 입력 시 실시간 반영
• 변수(#{이름}) 사용 시 샘플 데이터로 표시
• MMS 선택 시 이미지 미리보기 포함
8
포인트 정보
▼
발송에 필요한 예상 포인트와 발송 후 잔여 포인트를 표시합니다.
항목 계산 방식
예상 발송 포인트 메시지 타입 단가 × 수신자 수
예상 잔여 포인트 현재 잔액 - 예상 발송 포인트
⚠️ 잔액 부족 시
예상 잔여 포인트가 음수인 경우 빨간색으로 표시되며, 충전 안내 링크가 표시됩니다.
