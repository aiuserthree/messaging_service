화면 요소 설명

1. 탭 메뉴

문자 템플릿 탭 일반문자 / 광고문자 / 선거문자
카카오 템플릿 탭 알림톡 / 브랜드톡
현재 활성 탭 광고문자 (강조 표시)

2. 광고문자 규정 안내

표시 내용 - (광고) 표기 필수
- 080 수신거부 번호 필수
- 발송 시간 제한 안내
스타일 정보성 알림 (info alert)

3. 검색 및 필터

카테고리 필터 전체/프로모션/세일·할인/신상품/이벤트
검색 대상 템플릿명

4. 새 템플릿 등록 버튼

클릭 시 템플릿 등록 모달 표시

5. 템플릿 목록 테이블

표시 컬럼 - 체크박스 (선택)
- NO (순번)
- 템플릿명
- 카테고리
- 타입 (SMS/LMS/MMS)
- 080 수신거부 번호
- 등록일
- 관리 (상세/삭제)
정렬 등록일 최신순 기본

6. 테이블 하단 액션

선택 삭제 체크된 템플릿 일괄 삭제
페이지네이션 페이지당 10건 표시

7. 템플릿 등록/수정 모달

모달 유형 등록 / 수정 (버튼 텍스트 변경)
수정 시 기존 데이터 자동 채움

8. (광고) 문구 입력

형식 (광고) + 사용자 입력 문구
필수 여부 필수
입력 예시 (광고) 톡벨쇼핑
최대 길이 20자 (40byte)

9. 080 수신거부 번호

형식 Select (등록된 번호 목록)
필수 여부 필수
번호 없는 경우 "마이페이지에서 080번호 등록" 안내
미리보기 형식 무료수신거부 080-XXX-XXXX

10. 메시지 내용 및 변수

바이트 제한 - SMS: 90byte
- LMS: 2000byte
- MMS: 2000byte
변수 버튼 #{이름}, #{전화번호}, #{변수1}, #{변수2}, #{변수3}
변수 삽입 클릭 시 커서 위치에 삽입

11. 이미지 첨부 (MMS)

표시 조건 MMS 선택 시에만 표시
최대 개수 3개 (개별 슬롯)
파일 제한 - 크기: 각 300KB 이하
- 형식: JPG, PNG, GIF
