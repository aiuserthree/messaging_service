발신프로필 등록

💡 카카오톡 채널(https://center-pf.kakao.com)에서 비즈니스 채널로 등록된 카카오톡 채널(발신프로필)만 등록 가능합니다.

카카오톡 채널 관리자(마스터 또는 매니저) 휴대폰번호를 입력해주세요.
카카오톡 채널 관리자(마스터 또는 매니저) 휴대폰번호를 입력해주세요. ✓ 인증되었습니다
쇼핑몰 > 종합쇼핑몰
카카오톡 채널 관리자센터에서 발신프로필별 최초 생성 시 선택했던 카테고리와 동일하게 선택해주세요
⚠️ 단, 등록된 카테고리가 잘못된 경우 카테고리로 전환

화면 요소 설명

1. 모달 컨테이너

모달 크기 중간 크기 (max-width: 500px)
배경 반투명 오버레이 (rgba(0,0,0,0.5))
닫기 방법 - X 버튼 클릭
- 취소 버튼 클릭
- ESC 키 입력
- 오버레이 클릭 (선택적)

2. 모달 헤더

제목 "발신프로필 등록"
닫기 버튼 우측 상단 X 아이콘

3. 안내 영역

안내 내용 카카오톡 비즈니스 채널만 등록 가능 안내
링크 https://center-pf.kakao.com (새 창)

4. 발신프로필 입력

입력 형식 @로 시작하는 채널 ID
필수 여부 필수
유효성 검증 - @로 시작
- 영문, 숫자, 언더스코어만 허용
- 최소 3자 ~ 최대 50자
예시 @tokbell, @my_channel_123

5. 담당자 휴대폰 번호

필수 여부 선택 (인증용)
입력 형식 숫자만 입력 (10~11자리)
인증요청 버튼 - 클릭 시 카카오 API로 인증 요청
- 발신프로필과 휴대폰 번호 일치 여부 확인
인증 결과 - 성공: "✓ 인증되었습니다" (초록색)
- 실패: 에러 메시지 표시 (빨간색)

6. 카테고리 선택

필수 여부 필수 (최소 1개)
최대 선택 3개
선택 방식 1. 1차 카테고리 선택
2. 2차 카테고리 선택
3. 선택된 카테고리가 태그로 추가
중복 검증 동일 카테고리 중복 선택 불가
삭제 태그의 X 버튼 클릭

7. 모달 푸터 버튼

취소 모달 닫기, 입력 내용 초기화
등록 - 유효성 검증 후 API 호출
- 성공 시 모달 닫기 + 목록 갱신
- 실패 시 에러 메시지 표시

API 명세

POST
/api/v1/kakao/profiles/verify-phone
// 휴대폰 인증 Request
{
  "profileId": "@tokbell",
  "phoneNumber": "01012345678"
}

// Response
{
  "verified": true,
  "message": "인증되었습니다"
}
// 또는
{
  "verified": false,
  "message": "발신프로필과 휴대폰 번호가 일치하지 않습니다"
}
POST
/api/v1/kakao/profiles
// 발신프로필 등록 Request
{
  "profileId": "@tokbell",
  "phoneNumber": "01012345678",
  "categories": [
    "쇼핑몰 > 종합쇼핑몰",
    "서비스 > IT/통신"
  ]
}

// Response
{
  "id": "profile-001",
  "profileId": "@tokbell",
  "status": "REGISTERED",
  "message": "발신프로필이 등록되었습니다"
}

에러 처리

PROFILE_NOT_FOUND 존재하지 않는 카카오톡 채널입니다
PROFILE_ALREADY_REGISTERED 이미 등록된 발신프로필입니다
PHONE_MISMATCH 발신프로필과 휴대폰 번호가 일치하지 않습니다
INVALID_CATEGORY 유효하지 않은 카테고리입니다
NOT_BUSINESS_CHANNEL 비즈니스 채널로 등록되지 않은 채널입니다

데이터 모델

interface ProfileRegisterRequest {
  profileId: string;        // @아이디 형태
  phoneNumber?: string;     // 숫자만 (선택)
  categories: string[];     // 최대 3개
}

interface ProfileRegisterResponse {
  id: string;
  profileId: string;
  status: 'REGISTERED' | 'PENDING';
  message: string;
}
