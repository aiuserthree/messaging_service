서브 네비게이션

검수 안내 배너
▼
알림톡 템플릿의 카카오 검수 절차를 안내합니다.
💡 검수 절차
1. 템플릿 등록
2. 카카오 검수 요청 (자동)
3. 검수 진행 (1~3 영업일)
4. 승인 또는 반려

검수중조회만 가능
승인발송사용, 복사
반려수정, 삭제, 반려사유확인

7
메시지 내용 입력
▼
알림톡 메시지 본문을 작성합니다.
💡 변수 사용
• #{변수명} 형태로 변수 삽입 가능
• 변수는 발송 시 실제 값으로 치환
• 자주 쓰는 변수는 버튼으로 빠른 삽입
⚠️ 검수 주의사항
• 광고성 문구 불가
• 정보성 메시지만 허용
• 마케팅/프로모션은 브랜드메시지 사용
8
버튼 설정
▼

버튼 타입설명
웹 링크외부 URL로 이동
앱 링크앱 스킴으로 이동
봇 키워드챗봇 키워드 전송
메시지 전달상담원 연결
💡 버튼 제한
최대 5개까지 추가 가능, 버튼명 최대 14자

• 메시지 입력 시 실시간 미리보기 반영
• 버튼 추가 시 즉시 표시
• 변수는 샘플 데이터로 표시

등록 버튼
▼
템플릿을 저장하고 검수 요청합니다.

임시저장등록 상태로 저장 (검수요청 X)
