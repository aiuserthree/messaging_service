등록된 알림톡 템플릿이 없습니다

알림톡 발송을 위해서는 카카오톡 채널에서

템플릿을 등록하고 승인받아야 합니다.

템플릿 등록 후 1~2 영업일 내 승인됩니다.

📌 알림톡 템플릿 안내

  • 알림톡은 정보성 메시지 전송을 위한 카카오 서비스입니다
  • 주문/배송 알림, 예약 확인 등 정보 전달 목적으로 사용합니다
  • 광고성 메시지는 알림톡으로 발송할 수 없습니다
  • 템플릿은 카카오 심사 후 승인되어야 사용 가능합니다

화면 요소 설명

1. 탭 메뉴

탭 구성 발신프로필 관리 / 알림톡 발송 / 브랜드톡 발송
현재 위치 알림톡 발송 (활성 상태)

2. 템플릿 미존재 안내 영역

표시 조건 - hasTemplate === false
- 승인된 알림톡 템플릿이 0개인 경우
레이아웃 화면 중앙 정렬, 최대 너비 500px

3. 안내 아이콘

아이콘 📋 (클립보드/문서 이모지)
크기 64px ~ 80px

4. 안내 제목

텍스트 "등록된 알림톡 템플릿이 없습니다"
스타일 24px, bold, 검정색

5. 안내 설명

주요 내용 - 템플릿 등록 및 승인 필요 안내
- 승인 예상 기간: 1~2 영업일
스타일 14px, 회색 (#666)

6. 알림톡 안내 박스

배경색 연한 파란색 (#f0f7ff)
안내 내용 - 알림톡 서비스 설명
- 사용 용도 (정보성 메시지)
- 광고성 메시지 발송 불가 안내
- 카카오 심사 승인 필요 안내

7. 템플릿 등록 버튼

버튼 텍스트 "템플릿 등록하러 가기"
클릭 동작 - 알림톡 템플릿 관리 페이지로 이동
- URL: /template-alimtalk.html
- 새 창으로 열기 (target="_blank")
스타일 Primary 버튼, Large 사이즈

8. 가이드 링크

텍스트 "템플릿 등록 가이드 보기 >"
링크 대상 카카오비즈니스 알림톡 가이드
https://kakaobusiness.gitbook.io/main/ad/infotalk/content-guide
열기 방식 새 창/탭에서 열기
