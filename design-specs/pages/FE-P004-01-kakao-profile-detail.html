화면 요소 설명

1. 모달 컨테이너

모달 크기 큰 크기 (max-width: 600px)
스크롤 내용이 길 경우 바디 영역 스크롤

2. 모달 헤더

제목 "발신프로필 상세"

3. 기본 정보 섹션

표시 정보 - 발신프로필 ID (@아이디)
- 카카오톡 채널명
- 등록일
- 상태 (배지)
- 브랜드메시지 사용여부 (Y/N)
상태 배지 색상 - 등록: 회색
- 검수중: 노란색
- 활성: 초록색
- 중단: 주황색
- 차단: 빨간색

4. 담당자 휴대폰 번호

표시 형식 마스킹 처리 (010-****-5678)
번호 없는 경우 "등록된 정보가 없습니다"

5. 카테고리 섹션

표시 형식 태그 형태로 나열
최대 개수 3개

6. 등록 이력 섹션

표시 정보 - 일시 (YYYY-MM-DD HH:mm:ss)
- 액션 (등록, 상태변경 등)
- 수행자 (사용자 이메일 또는 '카카오')
정렬 최신순 (상단)

7. 관련 템플릿 섹션

표시 정보 등록된 템플릿 개수
템플릿 관리 버튼 - 클릭 시 알림톡 템플릿 관리 페이지로 이동
- 해당 프로필 필터 적용

8. 상태별 안내

검수중 파란색 info, 검수 진행 중 안내
중단 주황색 warning, 서비스 중단 안내
차단 빨간색 danger, 정책 위반 차단 안내

9. 모달 푸터 버튼

삭제 버튼 - 조건: 템플릿이 0개인 경우만 활성화
- 클릭 시: 삭제 확인 모달 표시
- 비활성 시 안내 문구 표시
수정 버튼 - 조건: 상태가 '활성'인 경우만 활성화
- 클릭 시: 수정 모달로 전환
닫기 버튼 모달 닫기

데이터 모델

interface ProfileDetail {
  id: string;
  profileId: string;
  channelName: string;
  status: ProfileStatus;
  brandMessageEnabled: boolean;
  phoneNumber?: string;       // 마스킹됨
  categories: string[];
  templateCount: number;
  history: ProfileHistory[];
  registeredAt: Date;
}

type ProfileStatus = 
  | 'REGISTERED'  // 등록
  | 'PENDING'     // 검수중
  | 'ACTIVE'      // 활성
  | 'SUSPENDED'   // 중단
  | 'BLOCKED';    // 차단

interface ProfileHistory {
  timestamp: Date;
  action: string;
  detail?: string;
  actor: string;
}

- 발송 이력이 있는 경우 (선택적)
안내 문구 "※ 템플릿이 있는 프로필은 삭제할 수 없습니다"
