1
모달 헤더

알림톡 템플릿 등록 모달 타이틀과 닫기 버튼입니다.

2
메시지 내용 입력

알림톡 메시지 본문을 작성합니다.

  • 변수는 #{변수명} 형식으로 입력
  • 최대 1000자까지 입력 가능
  • 입력 시 실시간 글자수 표시
3
버튼 설정

알림톡 하단 버튼을 설정합니다.

  • 버튼 타입: 웹링크/앱링크/배송조회 등
  • 버튼명 및 링크 URL 입력
  • 최대 5개까지 추가 가능
4
미리보기

카카오톡 알림톡 형태로 미리보기를 제공합니다.

  • 실시간으로 입력 내용 반영
  • 실제 발송될 형태와 동일
5
액션 버튼

템플릿 등록을 완료하거나 취소합니다.

  • 취소: 모달 닫기
  • 검수 요청: 카카오 검수 신청 및 저장

참고: 알림톡 템플릿은 카카오 검수 후 승인되어야 사용 가능
