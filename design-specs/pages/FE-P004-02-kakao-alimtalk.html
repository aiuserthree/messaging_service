화면 설명서
kakao-send-alimtalk.html · 알림톡 발송
1
서브 네비게이션
▼
카카오톡 기능의 탭입니다. 알림톡 발송이 활성화되어 있습니다.
2
발신프로필 선택
▼
알림톡을 발송할 발신프로필을 선택합니다.
💡 선택 조건
• 활성(ACTIVE) 상태의 프로필만 표시
• 프로필이 없으면 등록 안내 페이지 표시
3
템플릿 선택
▼
사전에 승인받은 알림톡 템플릿을 선택합니다.
조건설명
승인 상태승인(APPROVED) 템플릿만 선택 가능
프로필 연동선택한 프로필에 등록된 템플릿만 표시
⚠️ 템플릿 없을 시
승인된 템플릿이 없으면 kakao-send-alimtalk-before.html 안내 페이지로 이동
4
변수 값 입력
▼
템플릿에 포함된 변수의 값을 입력합니다.
💡 변수 형식
• #{변수명} 형태로 템플릿에 정의
• 선택한 템플릿에 따라 동적으로 입력 필드 생성
• 엑셀 업로드 시 컬럼명이 변수명과 매칭
5
수신번호 입력
▼
알림톡을 받을 수신자 번호를 입력합니다.
입력 방식설명
직접입력한 줄에 하나씩 번호 입력
주소록저장된 주소록에서 선택
엑셀 업로드전화번호 + 변수값 컬럼 포함
6
대체 메시지 설정
▼
카카오톡 미가입자에게 발송할 대체 SMS를 설정합니다.
옵션설명
대체 발송 사용체크 시 미가입자에게 SMS 발송
대체 메시지 내용SMS로 발송할 내용 (90byte 제한)
추가 비용SMS 단가 7.4원 별도 적용
7
카카오톡 미리보기
